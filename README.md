# Advanced Rider Assistance System (ARAS) — AI Smart Helmet Ecosystem

An open-source, cost-optimized, multi-stage AI Smart Helmet and Scooter integration system designed to bring high-end automotive safety, smart interlocks, and voice-intelligence features to two-wheelers.

---

## 🚀 Project Overview

The ARAS Ecosystem is split into two primary hardware modules—the **Helmet Unit** (powered by an ESP32-S3) and the **Scooter Interlock Unit** (powered by an ESP32 WROOM-32). By transitioning from premium, over-specified development kits to purpose-driven components, this design achieves a **39% cost reduction** compared to original blueprints while preserving all core safety features.

### Key Functionalities
1. **Smart Ignition Interlock:** The scooter will not start unless the system detects that the helmet is actively being worn and securely strapped.
2. **Crash & SOS Detection:** A calibrated 6-axis IMU checks for extreme deceleration/impact vectors to fire automated distress alerts.
3. **Gemini Voice Assistant:** Local voice-activation ("Hey Helmet") streams captured audio directly to the Gemini API, generating smart, contextual voice responses played back directly inside the helmet shell.

## 📊 Cost-Optimization Blueprint

| Stage | Sub-System | Optimized Component Choice | Economic Impact | Technical Justification |
| :--- | :--- | :--- | :--- | :--- |
| **Stage 1** | Helmet Core | SIM800L (2G) & Generic NEO-6M | **Saves ₹600** | 2G handles baseline SMS/Calls perfectly; upgraded to 4G only in Stage 3. |
| **Stage 1** | Scooter Core | Bare ESP32 WROOM Module | **Saves ₹100** | Eliminates development board PCB overhead for production deployment. |
| **Stage 2** | Audio Array | MAX98357 + 0.5W Mini Speaker | **Saves ₹320** | Replaces expensive bone conduction with acoustic cavity helmet speakers. |
| **Stage 2** | Eye Sensing | Raw IR LED + Phototransistor | **Saves ₹60** | Bypasses packaged module markups; identical performance. |
| **Stage 3** | Blind Spot | Dual HC-SR04 Ultrasonic Sensors | **Saves ₹400** | Replaces VL53L0X Laser TOF; $\pm$3cm threshold accuracy is ideal for 1.5m ranges. |
| **Stage 3** | Vision Engine | Reused OV2640 on Swivel Mount | **Saves ₹380** | Rear camera from Stage 2 moves dynamically to forward-facing. |

**Financial Summary:** Grand Total dropped from **₹5,910** to **₹3,620**, yielding a **39% overall cost reduction** without compromising user safety.

## 🛠️ Hardware Architecture & Pin Mapping

### 1. Helmet Unit (ESP32-S3 WROOM-1)
* **MPU6050 (IMU):** SDA (GPIO 4), SCL (GPIO 5)
* **Strap Switch (Tactile Button):** GPIO 6 (Internal Pull-Up)
* **Eye Blink Sensor (Raw IR Phototransistor):** GPIO 7 (Analog Input)
* **INMP441 I2S Microphone:** WS (GPIO 41), BCK (GPIO 42), SD (GPIO 2)
* **MAX98357 I2S Amplifier:** WS (GPIO 18), BCK (GPIO 17), SD (GPIO 16)

### 2. Scooter Unit (ESP32 WROOM-32)
* **Opto-Isolated Relay (Ignition Switch):** GPIO 12
* **Status Buzzer:** GPIO 13

## 🛡️ Non-Negotiable Safety Safeguards
> ⚠️ **CRITICAL CONFIGURATIONS:** Do not alter or substitute the following components under any circumstances:
> * **Opto-isolated Relay:** Isolates the ESP32 from dangerous 12V back-EMF voltage spikes generated by the scooter ignition coils.
> * **TP4056 Protection Circuitry:** Prevents catastrophic Li-ion battery runaway, swelling, or thermal failures inside the helmet padding.
> * **Calibrated Fall Detection:** The MPU6050 must be dynamically calibrated relative to the helmet's mass to eliminate false alarms caused by road bumps.

## 🔧 Installation & Compilation Guide

1. Clone the repository to your local system.
2. Install the following libraries via the Arduino IDE Library Manager:
   * `Adafruit MPU6050`
   * `Adafruit Sensor`
   * `ArduinoJson` (Required for handling Gemini API payloads)
3. Open `Helmet_Unit.ino` and update your network credentials along with your `GEMINI_API_KEY`.
4. Flash `Helmet_Unit.ino` to your ESP32-S3 board.
5. Flash `Scooter_Unit.ino` to your standard ESP32 board.
